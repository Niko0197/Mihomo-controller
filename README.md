Быстрая, красивая и высокопроизводительная веб-панель управления ядром **Mihomo (Clash)** на роутерах Keenetic с установленным Entware (включая **XKeen**).

Панель выполнена в стиле **Material 3 (Dark Theme)**. Полностью написана на чистом JavaScript / Node.js **без сторонних тяжёлых фреймворков и NPM-зависимостей**, что обеспечивает нулевую нагрузку на процессор и минимальный расход оперативной памяти роутера.

---

## ✨ Ключевые возможности

### 🚀 ⚡ Мгновенное переключение устройств (< 50мс)
- **Точечное управление гаджетами**: Включение/выключение VPN и выбор прокси-групп (`🚀Auto-Best`, `⚙️Manual 1-3`, `DIRECT`) для каждого смартфона, ПК или ТВ отдельно.
- **Параллельный сброс сокетов (2мс)**: Точечный разрыв активных соединений только переключаемого устройства без замирания сети на ПК и других гаджетах.
- **Защита от утечек IPv6 Privacy Extensions**: Умное отфильтровывание динамических временных IPv6-адресов смартфонов (iOS/Android), исключающее застревание мобильного трафика (YouTube, Telegram) в блокировках РКН.

### 🛠️ Быстрые правила маршрутизации (Quick Rules)
- **Удобный конструктор**: Добавление кастомных правил (домены, IP, подсети) в 1 клик.
- **Интерактивные выпадающие списки**: Улучшенные неперекрывающиеся селекторы с поддержкой высокой специфичности слоя (`z-index: 999999`) и 100% матовым фоном.
- **Живая проверка в памяти**: Применение правил «на лету» без полной перезагрузки ядра и без разрыва чужих сокетов.

### 📟 Встроенный системный мониторинг роутера
- **Точный учёт ОЗУ в МБ**: Реальное отображение потребления оперативной памяти в формате `RAM: 53% (268 / 512 МБ)`, нагрузки на ЦП (`%`) и температуры роутера (`°C`).
- **Интерактивный accordion-график**: Раскрывающийся график истории нагрузки роутера за последние 60 секунд с плавными iOS-анимациями.

### 🔄 Обновление ядра Mihomo и откат версий панели
- **Управление ядром Mihomo**: Обновление и откат релиза ядра прямо из веб-интерфейса.
- **История из 15 GitHub релизов**: Просмотр списков изменений (What's Changed) с автоопределением архитектуры процессора (`arm64`, `arm32v7`, `mipsle` с softfloat).
- **Переключение веток и откат коммитов**: Быстрый переход между ветками (`main` / `Dev`) и откат к любому из последних 15 коммитов в 1 клик.

### 📊 Активные соединения и живой трафик
- **Посекундный мониторинг скоростей**: Отслеживание входящего и исходящего трафика устройств в реальном времени.
- **Накопительный дельта-анализ**: Раздельный учёт объёма переданных данных через VPN-туннели и напрямую (DIRECT).
- **Управление сокетами**: Просмотр активных подключений с возможностью разорвать любое конкретное соединение.

### 📋 Системные логи ядра
- **Real-time стриминг**: Живой поток логов с разбивкой по категориям (`Debug`, `Info`, `Warning`, `Error`).
- **Smart Scroll Lock**: При прокрутке истории логов вверх автоскролл приостанавливается, не дёргая экран при поступлении новых записей.

## 🚀 Установка

Для первой установки откройте SSH-консоль вашего роутера и выполните одну команду:

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/Niko0197/Mihomo-controller/main/install.sh)"
```

Скрипт автоматически:
- ✅ Проверит наличие Node.js, curl, tar
- ✅ Установит файлы панели в `/opt/root/mihomo-controller/`
- ✅ Создаст службу автозапуска в Entware
- ✅ Запустит веб-интерфейс на порту **4000**

После установки веб-панель доступна по адресу: **http://192.168.1.1:4000**

---

## 🔄 Обновление

Для обновления панели до свежайшей версии выполните ту же команду:

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/Niko0197/Mihomo-controller/main/install.sh)"
```

Скрипт **автоматически сохранит все ваши настройки и данные**:
- `clients_db.json` — сохранённые имена и группы устройств
- `tor_bridges.json` — пользовательские Tor-мосты
- Бэкапы конфигураций и логи

## 📋 Требования

| Требование | Описание |
|---|---|
| **Роутер** | Keenetic с поддержкой USB-накопителя |
| **Entware** | Настроена среда OPKG (EXT4 + SWAP-раздел от 512 МБ) |
| **XKeen** | Форк XKeen (с поддержкой Mihomo/Clash) установлен и запущен |
